# 💻 Silver-J IDE

Silver-J IDE is a Windows Forms-based Integrated Development Environment (IDE) developed using C# and .NET Framework.  
It provides a lightweight platform for creating, editing, and managing Java and web-based projects with built-in execution support.

---

## 🚀 Features

- 📝 Code Editor with syntax highlighting
- 📂 Project creation and management
- 🌐 Support for Java, HTML, CSS, and SQL files
- ▶ Built-in compile and run functionality
- 📑 Sample project templates included
- 🖥 User-friendly Windows Forms interface

---

## 🛠 Tech Stack

- **Language:** C#
- **Framework:** .NET Framework
- **UI:** Windows Forms
- **IDE Used:** Microsoft Visual Studio
